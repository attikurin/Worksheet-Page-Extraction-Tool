ワークシートページ切り出しツール

教科書や資料集のPDF、画像ファイルから必要なページだけを切り出し、1枚のA4用紙に自由にレイアウトして印刷用PDFを作成できるWebアプリです。

概要

「教科書のp.23-25だけを印刷したい」「デジタル教科書のスクリーンショットを並べて1枚のプリントにしたい」といった教育現場の声に応えるために開発されました。
サーバーにデータを送信せず、すべての処理がブラウザ上で完結するため、機密性の高い資料も安心して扱えます。

主な機能

PDF/画像対応: PDFファイルおよび画像ファイル（JPG, PNG等）をドラッグ＆ドロップで読み込めます。

ページ指定切り出し: PDF読み込み時に全ページのサムネイルを表示し、必要なページだけをクリックまたは範囲指定で抽出できます。

柔軟なレイアウト:

1ページ / 枚

2ページ / 枚（2分割）

4ページ / 枚（4分割）

用紙設定: A4用紙の「縦置き」「横置き」に対応。

並び替え・編集: 取り込んだ素材の順序変更や削除が簡単に行えます。

完全クライアントサイド動作: アップロードされたファイルはサーバーに送信されず、すべてブラウザ（ローカル）内で処理されます。

使い方

ファイルを開く: worksheet_extractor.html をWebブラウザ（Chrome, Edge, Safariなど）で開きます。

素材の追加: 左側のエリアにPDFまたは画像ファイルをドラッグ＆ドロップします。

ページの抽出（PDFの場合）:

PDFをドロップするとサムネイル一覧が表示されます。

使いたいページをクリックして選択するか、ページ番号（例: 1-3, 5）を入力して指定します。

「選択したページを抽出」ボタンを押すと、リストに追加されます。

配置の調整: リスト内のアイテムを「↑」「↓」ボタンで並び替えたり、「削除」ボタンで不要なものを消したりできます。

レイアウト確認: 右側のプレビューエリアで、配置やレイアウト（分割数、用紙の向き）を確認します。

PDF作成: 右上の「PDFを作成」ボタンを押すと、レイアウトされた状態のPDFファイルがダウンロードされます。

技術スタック

本ツールは単一のHTMLファイルで構成されており、以下のライブラリをCDN経由で使用しています。

HTML5 / JavaScript (ES6+)

Tailwind CSS: UIデザイン・スタイリング

PDF.js: ブラウザ上でのPDFレンダリング

日本語フォント対応設定（CMaps, Standard Fonts）適用済み

jsPDF: 画像からのPDF生成

動作環境

最新のWebブラウザ（Google Chrome, Microsoft Edge, Safari, Firefoxなど）

インターネット接続（初回起動時にCDNからライブラリを読み込むため必要です。一度読み込めば、タブを閉じない限りオフラインでも動作し続けます）

注意事項

文字化けについて: 一部のPDF（フォントが特殊な方法で埋め込まれている場合など）では、プレビュー時に文字が表示されないことがあります。本ツールでは日本語対応（CMaps/Standard Fonts読み込み）を行っていますが、全てのPDFの完全な表示を保証するものではありません。

セキュリティ: 読み込んだファイルは外部サーバーには送信されません。ブラウザのメモリ内でのみ処理されます。
